# Agent Skills

A collection of reusable skills that can be used for any AI agents.

## Skills

| Skill |	Description |
|-------|-------------|
| [career-biographer](skills/career-biographer/) | Reconstructing career history through conversational interviewing, memory retrieval, fact-checking, and storytelling—turning fragmented experiences into a structured career knowledge base for interviews, resumes, LinkedIn, and other professional materials. |

## Installation

Install a specific skill with:
```bash
npx skills add githubstig/agent-skills --skill <skill-name>
```

For example:
```bash
npx skills add githubstig/agent-skills --skill career-biographer
```

Or just manually copy & paste a specific skill somewhere if you know what you are doing ☺️
